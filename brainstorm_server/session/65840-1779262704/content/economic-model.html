💸 破产与利息/强平机制方案选择

如何重塑游戏的流动性危机？请选择最契合您预期的方案：

A

引入融资与强平机制 (推荐)

支持现金变为负数（即负债）。每日产生万分之五或百分之一的利息。当 负债 / 总资产 > 70%（维持担保比例吃紧）时触发 Margin Call。若不及时主动卖股还债，日终将以 95% 强制折价平仓。这极致地模拟了“赌徒输红眼”的贪婪与强平惩罚。

B

每日自动垫付平仓 (Auto-Liquidation)

不允许现金过夜为负。日结算时，若现金不足以支付生活成本或事件支出，系统在结算时刻强制按当前收盘价自动卖出价值对应的股票以补足头寸。虽免去了复杂的融资预警，但丧失了杠杆和利息的策略趣味性。

C

保留无杠杆但软化破产惩罚

现金不可为负。如在结算时现金不足，会强制弹出“应急借贷”或“变卖家产”等随机悲惨生活事件（例如：将电脑以极低价抵押给亲友，或者身体不适去借高利贷）。以此保护玩家不直接 Game Over，但无法进行主动杠杆交易。

方案 A (融资强平) 优势

  • 高度还原现实股票市场的“杠杆陷阱”，完美展现贪婪人性
  • 利息系统给玩家施加隐性时间成本，迫使玩家提高资金周转率
  • 允许玩家在有把握的重组利好下“孤注一掷”加杠杆，博取超额收益

方案 A (融资强平) 挑战

  • 实现难度相对较高，需在核心数据流中引入负债、利息和强平线的状态管理
