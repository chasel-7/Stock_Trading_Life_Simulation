1. 技术栈与系统边界

后端框架 Python 3.11+ / FastAPI (基于 Starlette 与 Pydantic，高性能且开发敏捷)
关系型数据库 SQLite (单文件存储，采用 SQLAlchemy / SQLModel ORM 驱动，开发零运维成本)
持久连接层 FastAPI WebSockets (处理 PVP 房间加入、心跳维持、匹配队列状态下发)
离线优先 (Frontend) React 18 + LocalStorage。日常单机或对局中的股票看盘、场景选择在本地实时渲染，对局结束时统一提交校验。

2. 核心数据库表结构设计 (ORM)

users (用户表)
- id: VARCHAR (主键, 微信 OpenID 或游客 UUID)
- username: VARCHAR (玩家昵称)
- avatar_url: VARCHAR (头像链接)
- elo_rating: INTEGER (PVP 天梯匹配分, 默认 1200)
- created_at: DATETIME

game_records (游戏结算记录表)
- id: INTEGER (自增主键)
- user_id: VARCHAR (外键)
- role_type: VARCHAR (角色：互联网人/销售经理...)
- final_cash: FLOAT (最终流动资金)
- final_assets: FLOAT (最终总资产)
- profit_rate: FLOAT (最终收益率)
- transaction_log: TEXT (以 JSON 存储的交易明细：[ {day, stock, type, price, qty}, ... ])
- score_metrics: TEXT (结算四维雷达图得分及称号)
- is_verified: BOOLEAN (是否通过防作弊重放校验)
- created_at: DATETIME

pvp_matches (PVP 对局房间表)
- id: VARCHAR (UUID, 主键)
- match_seed: VARCHAR (生成相同行情和事件的随机种子)
- status: VARCHAR (MATCHING / PLAYING / FINISHED)
- total_players: INTEGER (对局人数, 默认 4)
- duration_limit: INTEGER (最大限制时长，单位秒，默认 900 秒 / 15分钟)
- created_at: DATETIME

pvp_participants (PVP 玩家状态关联表)
- match_id: VARCHAR (复合主键, 外键)
- user_id: VARCHAR (复合主键, 外键)
- current_day: INTEGER (当前进展天数, 0~15)
- current_assets: FLOAT (实时资产，用于生成局内排行榜)
- final_assets: FLOAT (游戏结束时的最终资产)
- is_finished: BOOLEAN (是否在时限内完成了游戏)
- earned_elo: INTEGER (本局积分增减)

3. 防作弊重放验证流程

1. 种子回溯校验：后端根据对局对应的 match_seed 预先重跑行情，拿到每日每支股票的真实价格波动区间。
2. 日志重放计算：
   - 初始资金 ➔ 结合 transaction_log 中的买卖点。
   - 验证买入/卖出时的股票价格是否在该交易日该股票的最高/最低价区间内。若偏离超过合理阈值（滑点误差），直接判定为作弊！
   - 重算交易手续费、每日生活费和角色日薪扣减。
3. 终审：若重算结果与客户端上报的 final_assets 误差 < 0.01%，判定为“验证通过”；否则记为作弊。

4. 异步 PVP 匹配与结算机制

  • 匹配大厅与在线队列：FastAPI 内存中维护一个 MatchmakingQueue。玩家点击匹配，加入相应分段的队列（基于 elo_rating ± 200）。
  • 游戏开始：满 4 人时，后端创建 pvp_matches 记录，广播 match_id 和 match_seed，玩家进入单人游戏副本。
  • 实时进度广播：当玩家在本地过完一天，客户端发送一次轻量级心跳数据包 {day: x, assets: y}。后端接收后更新 pvp_participants，并通过 WebSocket 广播给同房间其他人，更新局内实时排行榜，提升对抗紧张感。
  • 超时与强制结算：对局创建 15 分钟后，后端定时任务扫描。未完赛的玩家状态标记为 is_finished = false，按已提交的最晚一天资产进行强制结算，并扣除天梯分。
  • 天梯分 Elo 结算公式：根据 4 人的最终资产排名发放 Elo 积分，例如第一名 +30 分，第二名 +10 分，第三名 -10 分，第四名 -30 分。
