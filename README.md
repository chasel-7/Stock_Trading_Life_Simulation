# 🎮 股票人生模拟器 (Stock Life Simulator)

> 所有的选择都有价格。

一款以真实A股历史数据为基底的**人生模拟+股票交易策略游戏**。

## 🎯 游戏特色

- 📈 **真实行情体验**：基于A股历史数据，价格实时步进跳动
- 🌙 **场景式社交**：盘后选择去酒吧、大排档还是回家，每个选择都有价格
- 🧠 **认知偏差诊断**：追涨杀跌？损失厌恶？游戏结束后帮你照镜子
- ⭐ **四维评分**：投资智慧 / 社交回报 / 生活平衡 / 心态稳定

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 运行测试
npm run test

# 端到端测试
npm run test:e2e

# 生产构建
npm run build
```

## 🛠 技术栈

- **游戏引擎**: Phaser 3
- **语言**: TypeScript
- **构建**: Vite
- **测试**: Vitest + Playwright

## 📁 项目结构

```
src/
├── config/       # 游戏配置、常量
├── data/         # 角色、场景、行情数据
├── managers/     # 游戏状态、股票数据、存档管理
├── models/       # TypeScript类型定义
├── scenes/       # Phaser场景（盘前/盘中/盘后/结算/复盘）
├── ui/           # UI组件（图表、卡片、弹窗、主题）
└── utils/        # 工具函数（心情计算、偏差检测、评分）
```

## 🎮 游戏流程

```
角色选择 → 盘前简报 → 盘中交易 → 盘后场景 → 日结算 → (重复N天) → 终局复盘
```

### 角色系统
- 💻 **程序员**：信息敏锐，研究效率高
- 🗣️ **销售**：人脉广，社交成本低
- 🎨 **自由职业者**：手续费低，收入波动大
- 🏛️ **公务员**：稳定工资，研究间隔短

### 盘后场景
根据当日心情解锁不同场景：酒吧、大排档、公园、便利店、书店等。
每个选择影响资金、心情、社交关系。

### 复盘系统
- 📊 持仓揭秘：回顾每只股票表现
- 📈 资产曲线：全程资产变化可视化
- 🧠 偏差诊断：追涨杀跌/过度交易/损失厌恶等6大认知偏差
- 🕸️ 雷达图：投资智慧/社交回报/生活平衡/心态稳定四维评分
