# 📈 股票人生模拟器 (Stock Life Simulator)

> **核心哲学：所有的选择都有价格。**
> 本项目是一款模拟真实股市环境与职场人生抉择的轻量级策略类 Web 游戏。玩家将扮演不同的职业身份，在有限的 15 天时间里，平衡流动现金与股市持仓资产，应对职场突发状况与社交活动，诊断并克服投资偏见，最终争夺天梯排行的荣耀。

---

## 🎮 游戏核心玩法与特色

1. **多重职业选择**：
   - 💻 **互联网打工人**：日薪较高，可获得额外的每日行业情报线索。
   - 👔 **销售经理**：起薪中等，享有商务交际场景的折扣特权。
   - 🧘 **自由职业者**：极高流动资金开局，工资根据行情随机浮动。
   - 🏛️ **体制内员工**：极低开局资金，但起薪与生活费非常稳定，享有内部独家研报。

2. **动态行情与情报系统**：
   - 包含 15 支对应真实历史数据的虚拟股票，价格走势完全由随机种子决定。
   - 玩家可通过日常社交场景（公园散步、刷手机、大排档、酒吧、高级餐厅、SPA会所）消耗资金获取个股情报。
   - **动态情报预测**：服务端通过未来 3 日行情趋势自动分析个股状态（暴涨、大涨、震荡、阴跌、暴跌），并在前端反馈给玩家用于投资参考。

3. **职场突发事件**：
   - 随机触发的部门事件，如 **【紧急开会】** 会在 14:00 强制停用当天后续的股票交易；**【项目分红】** 可给予额外现金奖励。
   - 生活挑战（如家电坏了、亲友借钱、伴侣埋怨礼物支出等）将实时考验玩家的流动资金链管理。

4. **PVP 联机匹配与机器人备份**：
   - 支持实时 WebSocket 双人天梯联机匹配。
   - 排队寻找对手，若**超过 5 秒**未成功匹配到真实玩家，系统将自动指派一个 **电脑玩家 (Bot)** 陪同对局，并在右下角看板实时显示其天数和资产进度。

5. **行为偏见诊断系统**：
   - 在每局 15 天结束后，系统会自动诊断玩家在操盘过程中的典型行为偏差。
   - 包含 **损失厌恶偏见（Loss Aversion）** 诊断（准确分析调仓均价与盈亏微调）。
   - 计算并展现最终的雷达图四维得分，帮助玩家复盘是“职业股民”还是“社交达人”。

## 🛠️ 技术栈说明

* **后端 (Backend)**：
  - Python (FastAPI, SQLModel, Uvicorn, Websockets)
  - 单元测试框架：Pytest
* **前端 (Frontend)**：
  - HTML5, Javascript, CSS
  - React 19 + Vite 8
  - 状态管理：Zustand 5

---

## 🚀 快速启动指南

### 1. 启动后端服务器

确保已安装 Python 3.10+ 环境。进入 `backend` 目录：

```bash
cd backend
```

激活你的 Python 3.11 虚拟环境：

```bash
source ~/Developer/soft/venv_3.11.9/bin/activate
```

安装依赖（如需补充）：

```bash
pip install -r requirements.txt
```

启动 FastAPI 服务：

```bash
uvicorn main:app --reload --port 8000
```
*后端将在 `http://localhost:8000` 监听。*

---

### 2. 启动前端项目

进入 `frontend` 目录：

```bash
cd ../frontend
```

安装 Node 依赖：

```bash
npm install
```

启动 Vite 开发服务：

```bash
npm run dev
```
*前端将在 `http://localhost:5173` 运行，点击链接即可进入游戏大厅。*

---

## 🧪 运行测试

如需运行后端自动化测试套件（包括数据库操作、平仓验证、PVP 匹配与机器人逻辑）：

```bash
cd backend
~/Developer/soft/venv_3.11.9/bin/python -m pytest
```
