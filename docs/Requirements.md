📝 股票人生模拟器：需求规格说明文档 (V1.2 - 纯粹资产版)项目名称：股票人生模拟器（Stock Life Simulator）
核心哲学：所有的选择都有价格。
唯一维度：现金（Cash）与资产（Assets）。一、核心逻辑与资产模型1.1 唯一核心公式$$当日总结余 = 上日现金 + ( \sum 持仓价值 ) - 生活成本 - 社交/决策支出 \pm 事件随机损益$$资源转换：玩家手中的“钱”分为两类：场内本金：已购买股票的部分，随历史数据实时波动。流动现金：用于买入股票、支付生活费或购买“决策事件”（如请客、调研）。1.2 决策驱动机制游戏不再提供随机的认知心理，所有的“原画对话事件”本质上都是**“投资机会”或“损失风险”**。玩家需要判断：一套纸币进行决策，能否换回更高的投资回报？二、交易系统与“静态信息库”2.1 模糊化股票池（数据池）每局15支股票，背后同样历史的真实数据。关键点：每一代号股票都预挂了几条**“静态信息”**，这些信息根据该股在历史真实时间轴上的设定节点。2.2 信息获取逻辑（信息套利）静态数据库地图：例如：代号：消费-01在第8集会有真实的大涨（历史天事实）。事件触发：玩家在第7天选择“中午请人吃饭（花费500元）”。结果反馈：系统从静态库调取该股信息：“听说消费-01背后的大东家最近有重组动作。”三、影响资产的典型事件库（Event Categories）为了让“只有钱”的玩法也具备极高的策略性，我设计了三类影响资产的事件：3.1 社交套利类（主动支出换取信息）此类事件由玩家主动触发，消耗流动资金，换取确定性或概率性的市场预测。【午餐会】（消耗现金）：获得某支模糊股票未来3天的走势趋势（如：大概率上行）。【购买研报】（消耗现金）：解锁某支股票的“历史关键词”。（如：虽然代号是制造-03，但关键词提示“果链龙头”，资深玩家可据此判断真实身份）。【打点领班】（消耗现金）：获得下一周“固定生活费”减免的优惠（模拟资源置换）。3.2 工作场所风险类（被动损益与决策）此类事件在交易日随机跳出，考验玩家对“机会成本”的把控。【紧急开会】（决策权）：领导要求立即开会。选择A：参会损失。今日14:00后的交易权限，但可获得额外奖金1000元。选择B：带薪摸鱼。保留交易权限，但有50%的概率被抓，罚款3000元。【项目分红】（资产溢价）：因工作场所表现获得额外现金，取决于您之前在相关事件中的选择。3.3 生活突发类（刚性支出与生存挑战）【家电坏了】：强制支出2000元。【亲友借钱】： *选择A：借出。损失当前流动现金，但10天后返还120%（模拟高风险债权）。选择B：拒绝。无损失，但失去了后续一个可能的“内部消息”来源。【老婆指教】： *若今日大亏，触发强制支出：购买道歉礼物（金额随浮动比例波动）。四、交易与流程节点4.1 交易盈利 (09:30 - 15:00)实时决策： 15支股票价格随步进跳动。QTE干扰： “领导巡视”等即时事件，失败直接导致金钱损失。4.2 盘后社交（15:00 - 22:00）核心要点：玩家自主选择“晚上去哪儿”。去酒吧：消费高，信息杂（真假消息参半）。去书店：消费低，提升未来5天的交易佣金折扣。回家吃饭：无消费，无信息获取。五、终局结算奖金揭秘：依然保留。在破产或达标时，揭开15支股票的“历史面纱”。复盘报表：显示玩家由于“事件决策”带来的额外收益 vs 纯操盘收益，评估玩家是“职业股民”还是“社交达人”。
