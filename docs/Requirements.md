## 一、项目概述

### 1.1 产品定位

一款以真实A股历史数据为基底的**个人投资决策与心理模拟H5网页游戏**。玩家扮演一个刚接触股市的普通人，在15个交易日的周期里，通过交易决策、信息套利和生活事件抉择，体验"所有选择都有价格"的核心哲学，并作为镜子直观反射出玩家内心的情绪和投资认知偏差。

### 1.2 目标用户

- 对股市有好奇心但缺乏实战经验的年轻人
- 有一定炒股经验、希望在安全环境中复盘自身行为偏差的投资者
- 喜欢策略经营类游戏的休闲玩家

### 1.3 目标平台与分发

| 项目 | 说明 |
|------|------|
| **主平台** | H5 网页应用（移动端优先，全面兼容PC浏览器） |
| **分发渠道** | 微信文章内链接、公众号菜单、群聊/朋友圈分享 |
| **资质要求** | 无需游戏版号，个人即可快速部署上线 |

### 1.4 美术风格

**高端科技感（Fintech Premium Style）与轻都市漫画**相融合。主页面为高级感深灰底色，以高对比度的红绿霓虹色表示涨跌，配以平滑的分时过渡动效。事件卡片以漫画分镜呈现，整体调性沉稳、极富质感、带有些许黑色幽默。

## 二、核心游戏循环

每个交易日约 **10分钟**，分为以下阶段依次流转：

```
LOBBY（大厅）→ PRETRADE（盘前）→ TRADE（盘中）→ NIGHT（盘后社交）→ 日结算
                                                                    ↓
                                               循环 Day 1~15 或触发终局条件
                                                                    ↓
                                                          SETTLEMENT（终局复盘）
```

### 2.4 盘后社交阶段（NIGHT，约3分钟）

**场景式社交系统**：根据当日收益率解锁不同场景，每晚选择1个场景进入。

#### 2.4.1 场景解锁机制

以**当日收益率**（基于昨日总资产）决定可选场景，分5档累积解锁：

| 当日收益率 | 心情状态 | 解锁场景 |
|---|---|---|
| < -8% | 😱 大亏 | 🏠 回家吃泡面、🌳 公园散步 |
| -8% ~ -2% | 😔 小亏 | + 📱 刷手机、🍜 大排档 |
| -2% ~ +2% | 😐 平淡 | + 📚 书店、🏪 便利店买啤酒 |
| +2% ~ +8% | 😊 小赚 | + 🍺 酒吧、🍽️ 高级餐厅 |
| > +8% | 🤑 大赚 | + 🎤 KTV包场、💆 SPA会所 |

> **设计理念**：赚钱 = 选择权变多。亏钱时不是系统惩罚，而是"今天只能去这些地方"的生活真实感。场景选择本身承担了"消费冲动事件"的设计功能。

## 四、股票数据系统

### 4.1 股票池

**100支股票**，分为5个热门板块（每板块20支）：

| 板块 | 代号前缀 | 典型波动特征 |
|------|---------|------------|
| 🛒 消费 | 消费-01~20 | 稳健偏多，偶有爆发 |
| 💻 科技 | 科技-01~20 | 波动大，涨跌幅极端 |
| 🏭 制造 | 制造-01~20 | 趋势性强，慢涨慢跌 |
| 💊 医药 | 医药-01~20 | 受事件驱动明显 |
| 💰 金融 | 金融-01~20 | 波动小，随大盘走 |

### 4.2 每局抽取逻辑

- 每局15支 = 每个板块随机抽3支
- 其中2~3支标记为"推荐股"（盘前信息中高亮显示）
- **推荐股不代表一定涨**，用于测试权威偏见

### 4.3 数据来源与模糊化流程

```
真实A股历史数据
    ↓ 取10~15个连续交易日
    ↓ 模糊化：价格缩放到¥5~50，抹去日期/公司名/成交量
    ↓ 仅保留：开盘价 → 各步进价格 → 收盘价
    ↓ 挂载"静态信息节点"（基于真实历史事件设置）
    ↓ 分配代号（消费-01）和关键词（果链龙头）
```

## 五、事件系统

### 5.1 三层信息体系

| 层级 | 获取方式 | 内容 | 可靠性 |
|------|---------|------|--------|
| **第一层：免费信息** | 每天盘前自动获取 | 市场大盘趋势 + 行业板块热度 | 参考性 |
| **第二层：场景付费信息** | 盘后社交场景中获取 | 个股趋势/涨跌预测/真实身份关键词 | 30%~100% |
| **第三层：情报串联** | 自动触发（同股≥2条信息） | 高确信度综合研判 | ~90% |

### 5.2 场景内决策事件

进入盘后场景后，以卡片式呈现1~3个决策事件，不限时。事件内容因场景而异：

**示例 — 酒吧场景**：

| 事件 | 选项A | 选项B |
|------|-------|-------|
| 🍺 有人请你喝酒 | 喝：花¥200，获一条消息（质量随机） | 拒绝：无成本，无收益 |
| 📞 老板打电话来 | 接听：明天加班无社交但双倍日薪 | 挂断：正常流程，20%影响下次奖金 |
| 🤝 遇到前同事 | 聊聊：获一条行业信息 | 装没看见：无事发生 |

> 每个场景目标3~5个事件池随机抽取。

### 5.3 生活突发类事件（日结算阶段·被动触发）

| 事件 | 效果 |
|------|------|
| 🏠 家电坏了 | 强制支出¥2,000 |
| 👨‍👩‍👦 亲友借钱 | A: 借出流动现金20%，10天后返还120% / B: 拒绝，失去一个内部消息源 |
| 💍 老婆指教 | 当日大亏时触发，强制购买道歉礼物（金额=当日亏损×20%） |
| 🏥 身体不适 | 明天盘中交易时间缩短为3分钟 |
| 🎉 朋友请客 | 免费获得一条模糊信息 |

事件频率由角色决定（详见第三章角色表）。

### 5.4 设计原则

- **盘中零干扰**：交易时专注做一件事
- **盘后场景化**：信息获取、社交互动、工作事件全部融入场景叙事
- **结算随机性**：生活突发事件作为不可控因素，与场景选择解耦
- **消费即选择**：不再有独立的"消费冲动弹窗"，场景选择本身就是消费决策

## 六、经济模型

### 6.1 核心公式

```
当日总结余 = 上日现金 + 日薪收入 + 股票卖出所得
           - 买入支出 - 生活成本 - 场景花费
           - 生活突发事件损失
```

### 6.2 资金分类

| 类别 | 说明 |
|------|------|
| **流动现金** | 用于买股、付费、支付生活费 |
| **持仓市值** | 已购入股票，随行情实时波动 |
| **总资产** | 流动现金 + 持仓市值 |

### 6.3 交易手续费

- 每笔买入/卖出收取交易金额的 **1%**
- 书店场景可将手续费减半至0.5%（持续5天）
- 自由职业者天然手续费0.5%，书店可叠加至0.25%

### 6.4 自动平仓规则

- **负现金过渡**：盘中买股或盘后消费允许现金暂时跌入负数
- **自动平仓**：日结算阶段，若现金为负，按玩家预设策略强制卖出股票直至现金回正
- **三种策略**：
  1. 优先卖出浮盈最高股（处置效应，默认）
  2. 优先卖出浮亏最大股（理性止损）
  3. 优先卖出持仓市值最大股（流动性至上）
- **破产条件**：全部平仓后现金仍为负 或 总资产净值 ≤ 0

## 七、终局复盘系统（SETTLEMENT）

### 7.1 触发条件

- 💀 破产（现金归零）
- 🏆 达标（总资产 ≥ 起始资金 × 200%）
- 📅 到期（15个交易日结束）

### 7.2 复盘流程（约2分钟）

| 步骤 | 内容 | 优先级 | 状态 |
|------|------|--------|------|
| Step 1 — 揭开面纱 | 逐个揭示15支股票的真实身份 + 后续走势彩蛋 | P0 | ✅ 已实现 |
| Step 2 — 数据复盘 | 资产变化曲线 + 操盘收益 vs 事件决策收益对比 | P0 | ✅ 已实现 |
| Step 3 — 认知偏差诊断 | 6种偏差检测（追涨杀跌/沉没成本/过度交易/信息过载/损失厌恶/消费冲动） | P0 | ✅ 已实现 |
| Step 4 — 多维评分 | 四维雷达图（交易/风险/职业/信息）+ 个性化称号 | P0 | ✅ 已实现 |
| Step 5 — 分享海报 | 自动生成分享卡片（称号+收益率+二维码） | P2 | ❌ 未实现 |

### 7.3 认知偏差诊断矩阵

| 认知偏差 | 检测逻辑 | 正向引导 |
|---------|---------|---------| 
| 追涨杀跌 | 连涨后买入，连跌后卖出 | 提示追高风险 |
| 沉没成本 | 深度亏损持续持有不止损 | 鼓励理性割舍 |
| 过度交易 | 日均交易次数远超平均 | 提示频繁交易≠策略 |
| 信息过载 | 大量获取信息但未据此交易 | 提示信息≠行动力 |
| 损失厌恶 | 盈利快跑、亏损死扛 | 提示"割肉太慢、跑太快" |
| 消费冲动 | 盈利后频繁选择高消费场景 | 提示利润回吐心理 |

### 7.4 全服排行榜

| 排行类型 | 排行维度 | 刷新周期 | 状态 |

## 十三、设计哲学与约束

### 13.1 核心哲学

> **不嘲笑玩家，而是让玩家"旁观自己"。**  
> 每一局游戏就像一面镜子——你以为你在模拟炒股，其实你在暴露自己的决策本能。  
> 在安全的环境里犯错，在犯错中认识自己。

### 13.2 设计约束

1. **所有资源均以"钱"衡量** — 唯一维度是现金与资产，没有体力值、心情值等独立数值
2. **盘中零干扰** — 交易阶段专注交易，不插入弹窗/事件/社交
3. **消费即选择** — 不设独立的消费冲动弹窗，场景选择本身就是消费决策
4. **信息有价格** — 高质量信息需要高消费场景解锁，形成自然的投资/消费博弈
5. **没有最优解** — 角色、场景、策略没有唯一最优路线，鼓励多元玩法
