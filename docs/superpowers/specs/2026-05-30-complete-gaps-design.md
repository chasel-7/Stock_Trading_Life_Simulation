### 改动

## 二、情报串联增强

### 2.1 设计
- 前端已有串联显示代码（App.jsx:836-856），**不需要重写**

### 2.2 置信度标签
```

情报串联 (2个来源)  → ⭐⭐ 中置信度
情报串联 (≥3个来源) → ⭐⭐⭐ 高置信度

```

## 三、场景多事件卡片系统

### 3.1 架构

```
玩家选择场景 → 扣除场景基础费用 → 从事件池随机抽 1~3 张卡片
→ 逐张展示，每张 A/B 两个选项 → 选择后执行效果 → 下一张
→ 全部完成 → 显示汇总 → 进入日结算
```

### 3.2 新文件：`frontend/src/data/sceneEvents.js`

统一数据结构：
```js
{
    id: "bar_01",
    title: "🍺 有人请你喝酒",
    desc: "隔壁桌一个面善大哥主动给你倒了杯威士忌...",
    options: [
        {
            text: "喝！花 ¥200 聊聊",
            cost: 200,              // 额外花费（可选）
            effect: "info",         // "info" | "money" | "buff" | "none" | "gamble"
            infoQuality: 0.5,       // 情报准确率（effect=info时）
            moneyDelta: 0,          // 现金变化（effect=money时）
            buffType: null,         // buff 类型（effect=buff时）
        },
        {
            text: "谢绝好意",
            effect: "none"
        }
    ]
}
```
