# 股票人生模拟器 — 第六阶段（盘前推演、生活突发事件与自动平仓）开发计划

**Goal:** 实现开盘前的免费大盘行业与个股情报推送、夜晚扣费时的生活突发惩罚/福利事件，并提供玩家可自主配置的负现金强行自动平仓清算系统。

---

### Task 1: 编写盘前信息大厅与信息串联逻辑

- [x] **Step 1: 新增“盘前信息推送”步骤**
  每天开市前，强制显示一个弹窗，高亮提醒当天的板块热度和 2-3 支“主力推荐股”名录。
  
- [x] **Step 2: 编写多源情报合并算法**
  实现本地信息去重与聚类。当对同一支股票通过不同场景（如公园 + 大排档）收集到 2 条以上情报时，合成出带有“重组利好确信”、“出货预警”等 90% 以上高精准度的结论，并在情报面板进行高亮展示。

---

### Task 2: 盘后扣费与生活突发事件

- [x] **Step 1: 引入生活突发概率库**
  日终结算时，根据角色设定触发概率（打工人低、自由职业者高）派发突发卡片：如“家电损坏（扣 2000 现金）”、“身体不适（缩短操盘时间）”或“朋友请客（免费得情报）”。

---

### Task 3: 负流动现金过夜与自动平仓策略

- [x] **Step 1: 允许盘中与消费赤字过夜**
  玩家现金可以暂时跌为负数。但是在日结阶段，必须通过变现资产使现金回到 0 以上，否则触发清盘强制平仓。
  
- [x] **Step 2: 实现玩家自定义强制平仓策略**
  在配置界面中支持三种清算顺序：
  1. 优先卖出浮盈最高股（处置效应）
  2. 优先卖出浮亏最大股（理性割肉）
  3. 优先卖出市值最大股（流动性至上）
  并在结算时循环调用直到现金大于 0。若平仓完所有股票现金依然小于 0，则判定破产。
