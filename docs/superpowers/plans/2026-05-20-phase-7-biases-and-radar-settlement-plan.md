# 股票人生模拟器 — 第七阶段（行为偏见诊断与四维雷达结算图）开发计划

**Goal:** 深度分析用户的交易数据流，诊断其投资认知偏差（追涨杀跌、沉没成本等），并利用雷达图形式输出四维评分，进行最后的真实股票身份解密。

---

### Task 1: 开发交易偏见（Cognitive Bias）诊断算法

- [x] **Step 1: 编写追涨杀跌检测器**
  分析 `transactionLog` 中每一笔买入/卖出前 3 天的价格趋势，若绝大多数买入发生在线段急速上涨后，而卖出发生在线段连跌后，标记“追涨杀跌”偏差。
  
- [x] **Step 2: 编写损失厌恶与沉没成本检测器**
  若个股浮亏比例超过 30% 且持有天数超过 5 天依然拒绝止损，而浮盈股票持仓均短于 2 天，标记“损失厌恶/沉没成本”偏差。

- [x] **Step 3: 编写过度交易检测器**
  若日均交易换手率极高，标记“过度交易”偏差。

---

### Task 2: 绘制四维评估雷达图与揭秘身份

- [x] **Step 1: 整合四维评价数值计算**
  - 投资智慧：由最终收益率直接决定。
  - 心态稳定：受到交易次数、止损偏好、浮亏死扛等指标扣分影响。
  - 社交回报：受到夜间付费消息质量、高级消遣投入回报率正向拉动。
  - 生活平衡：由盘后休闲消费比例与日均健康指标衡量。

- [x] **Step 2: 绘制 Canvas/SVG 动态雷达图组件**
  在结算页面展示具有动画膨胀效果的四边形雷达图，标记各项能力等级，并赠与相应成就称号。

- [x] **Step 3: 真实身份大揭秘组件**
  在排行名次下方，翻牌显示 15 支股票在现实 A 股中对应的公司全称（如“贵州茅台”、“科大讯飞”等），并附带一段其真实历史的彩蛋背景介绍。
